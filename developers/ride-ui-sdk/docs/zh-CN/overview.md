# SDK 与公开范围

Motexa Ride UI SDK 用于开发运行在 Motexa App 内的 Web 仪表主题。主题订阅 App 已转换的标准车辆数据，并通过能力受限的消息接口请求展示交互。设备发现、连接、协议转换和授权由 App 管理。

当前版本：**SDK 1.5.0 / 消息 API 1.11 / Demo 0.2.0**。SDK 包版本和消息 API 版本分别描述开发包与通信契约，不应混用。

## 数据如何到达主题

```text
车辆 → App 连接与协议转换层 → 标准展示数据 → SDK → 主题
主题 → SDK 动作请求 → App 策略校验与执行 → 动作结果
```

SDK 不携带车辆协议实现，开发者不需要了解设备原始帧。数据字段存在不代表所有设备都支持；显示内容应依据当前能力、数值有效性和新鲜度。

## 仓库提供什么

| 内容 | 用途 |
| --- | --- |
| `vendor/ride-ui-sdk/` | 编译后的客户端、公共类型、合成回放和校验工具 |
| `theme/` | Vue / TypeScript 示例源码、清单、配置 schema |
| `mock-host.ts` 与 `mock-config.ts` | 浏览器模拟宿主和内存配置存储 |
| `reference/ride-ui-manifest-v1.json` | 公开 Web 主题清单参考 |
| `tools/` | 检查、构建、运行包、局域网分发和文档站工具 |
| `docs/` | 可在 GitHub 与网站复用的中英文 Markdown |

调试器只生成合成数据，不连接蓝牙或真实车辆，不读取用户骑行记录。开发包可独立构建，运行主题时仍需要 App 或模拟宿主提供数据。

## 能力与限制

SDK 主要提供展示数据兼容层，同时包含刷新、方向、主题设置等受控动作，**不是严格只读接口**。动作以宿主当前提供的能力为准，声明某个动作不代表获得执行权。

当前公开开发入口是 App 内 Web 主题。SDK 不提供独立第三方 Android App 接口、任意原生插件调用、设备驱动、车辆参数写入或跨 App 数据服务。公开类型中描述宿主环境的字段不代表公开了其他渲染器的实现入口。

## 发布与许可

示例代码和示例工具按根目录 `LICENSE.md` 指定的范围采用 MIT。`vendor/`、`reference/`、SDK 文档和 App 不在该 MIT 范围内。依赖的许可保留在 `THIRD-PARTY-NOTICES.md`。

App 源码、原生实现、底层协议文档、原始设备帧、设备凭证、签名材料和内部安装实现均不属于本仓库。公开资料只描述标准展示契约和主题开发流程。

接口名称可以公开。实际隔离由宿主沙箱、能力校验和授权执行完成；SDK 不承诺阻止他人独立实现类似接口。不要将 SHA-256 或消息会话标识视为安装授权或车辆凭证。

从 [快速开始](quick-start.md) 创建主题，再使用 [浏览器调试器](debugger.md) 验证表现。
